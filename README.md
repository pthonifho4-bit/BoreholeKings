# Borehole Kings Pty Ltd website

A responsive, static company website built with HTML, CSS and vanilla JavaScript. It is ready to upload to a GitHub repository and publish with GitHub Pages.

## Included
- `index.html` — homepage, services, approach, work showcase and contact form
- `styles.css` — responsive styling
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/bk-mark.svg` — simple editable brand mark

## Publish with GitHub Pages
1. Download and extract the ZIP file.
2. Create a new repository on GitHub.
3. Upload the contents of this folder (make sure `index.html` is in the repository root, not inside another nested folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site.

## Before going live
- Confirm the company name, phone number, service area and wording.
- Replace the illustrative stock photos with genuine Borehole Kings project photos for the strongest, most authentic result.
- Add the company's real logo if a final logo file is available.
- Add any registration, certification, warranty or compliance statements only if they are accurate and current.
